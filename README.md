# 💙 Sorpresa de Cumpleaños • Edición Especial (15 de Noviembre)

Una aplicación web interactiva y romántica desarrollada con **Next.js**, diseñada exclusivamente para celebrar un cumpleaños de una forma única, moderna y llena de detalles personalizados.

## ✨ Características Principales

* **💌 Mensaje con Efecto Máquina de Escribir:** Un saludo inicial animado que transmite un mensaje de amor de forma dinámica.
* **🎵 Reproductor de Música Nativo:** Integración con audio ambiental y efectos visuales de ondas sonoras animadas al reproducir.
* **📸 Galería de Momentos & Viajes:** 
  * Filtrado de fotos por categorías (*Viajes, Especiales, Familia, Amigos, Mascotas*).
  * Álbumes interactivos con grillas optimizadas.
  * Visor de fotos en pantalla completa con soporte de **navegación por teclado** (`Flecha Izquierda`, `Flecha Derecha` y `Escape` para cerrar).
  * Atajo especial para desplegar el mapa interactivo de la ruta del viaje a **Europa 2027** ✈️🚆.
* **🎟️ Cupones Interactivos con Memoria Local:**
  * Cupones 1 y 2 con integración directa a **WhatsApp** (`+5491140458808`) para coordinar fechas.
  * Cupón 3 con un **juego de pistas interactivo** con límite de intentos y efectos de confeti al ganar 🎉.
  * Persistencia de estado mediante `localStorage` para que los cupones canjeados no se pierdan al recargar la página.
* **💻 Easter Egg en Consola (F12):** Un saludo secreto personalizado y estilizado directo en la consola del navegador de desarrollador.

## 🛠️ Tecnologías Utilizadas

* **Framework:** [Next.js](https://next.js/) (React / App Router)
* **Estilos:** Tailwind CSS
* **Iconografía:** Lucide React
* **Efectos:** Canvas Confetti
